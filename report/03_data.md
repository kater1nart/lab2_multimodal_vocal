## 3. Паспорта наборов данных

### Набор 1. MagnaTagATune (основной: обучение, валидация, тест)

| Параметр | Значение |
|---|---|
| Источник | Law et al., ISMIR 2009; https://mirg.city.ac.uk/codeapps/the-magnatagatune-dataset (аудио — зеркало https://huggingface.co/datasets/confit/magnatagatune) |
| Лицензия | CC BY-NC-SA 3.0 (музыка лейбла Magnatune), только некоммерческое использование |
| Единица наблюдения | 29-секундный клип трека, mp3, моно, 16 кГц |
| Модальности | текст (исполнитель, альбом, название), аудио → ряд и спектрограмма |
| Метка | построена из краудсорсинговых тегов: синонимы объединены в 4 класса (правила — в ЛР1, `prepare_labels.py`) |
| Объём | 7 099 клипов, 3 420 треков, 444 альбома, 230 исполнителей |
| Классы | instrumental 34,6%, male 26,1%, female 25,0%, group 14,3% |
| Пропуски | пустых полей текста нет; 72% исходных клипов без вокальных тегов исключены (см. журнал) |
| Дубликаты | в среднем 2,1 клипа на трек (одинаковый текст у клипов одного трека); 3 почти-дубликата по аудио между частями удалены |
| Разбиение | по исполнителям: train 5 071 (163 исполнителя), val 1 019 (34), test 1 009 (33) |
| Дат релиза | нет |

### Набор 2. Song Describer Dataset + MTG-Jamendo (авторский набор для переноса)

| Параметр | Значение |
|---|---|
| Источник | Manco et al., 2023, https://zenodo.org/records/10072001 (описания), аудио — https://huggingface.co/datasets/renumics/song-describer-dataset; метаданные — https://github.com/MTG/mtg-jamendo-dataset (`raw.meta.tsv`) |
| Лицензия | описания — CC BY-SA 4.0; аудио Jamendo — лицензии Creative Commons (по трекам) |
| Единица наблюдения | трек Jamendo, 2-минутный фрагмент; используется окно 30–40 с |
| Модальности | текст (исполнитель, альбом, название из метаданных Jamendo), аудио → ряд и спектрограмма |
| Метка | извлечена правилами по ключевым словам из 1–5 текстовых описаний слушателей (`sdd_labels.py`); сами описания на вход не подаются |
| Объём | 706 треков → 344 с меткой → **281 с аудио** (106 исполнителей) |
| Классы | male 116 (41%), instrumental 101 (36%), female 35 (12%), group 29 (10%) |
| Период | релизы 2005–2017, медиана 2010; 2005–2009: 130 треков, 2010–2017: 151 трек |
| Пропуски | метаданных Jamendo нашлись для всех треков; аудио нет у 63 размеченных треков (вне «valid subset» зеркала) |
| Дубликаты | одинаковых текстов нет; один трек = один объект |

### Проблемы качества данных

| Проблема | Где | Влияние и что сделано |
|---|---|---|
| Слабая разметка: отсутствие тега не означает отсутствие признака | MTAT | клипы без вокальных тегов исключены |
| Противоречивые теги (вокал + «без вокала») | MTAT, SDD | исключены |
| Шум класса group | SDD | выборочная проверка: «the vocal and piano makes a great duet» и подобные фразы дают ложный group; ограничение отмечено в выводах |
| Разная частота дискретизации (16 кГц против полной полосы) | MTAT vs SDD | гармонизация S4; эффект измерен (раздел 8) |
| Сцепление класса с жанром (male — rock, group — opera) | MTAT | известно из ЛР1, учитывается при интерпретации |
| Изображения | обе | все 7 099 + 281 PNG построены без ошибок, NaN в рядах нет; битых изображений не обнаружено |
| Дисбаланс классов | обе | `class_weight="balanced"`, основная метрика — Macro-F1 |

### Журнал исключённых наблюдений

| Этап | Набор | Исключено | Причина |
|---|---|---|---|
| нет вокальных тегов | MTAT | 18 662 | метка не определяется |
| противоречие тегов | MTAT | 95 | вокал и «без вокала» одновременно |
| не скачалось аудио | MTAT | 4 | сетевой сбой (ЛР1) |
| почти-дубликаты по аудио | MTAT | 3 | косинусное сходство > 0,995 между частями split |
| нет упоминания вокала в описаниях / противоречие | SDD | 362 | метка не определяется |
| нет аудио в зеркале | SDD | 63 | трек вне «valid subset» (список — `results/excluded_sdd_no_audio.csv`) |
